# AI Smarty plugins

Official AI Smarty plugins. They connect an AI assistant to your AI Smarty account so you can set up, test and look after your website's AI agent from a conversation.

## Claude Code

```
/plugin marketplace add aismarty/aismarty-plugins
/plugin install aismarty@aismarty
```

What the plugin does, what it sends and what it fetches is described in [claude/README.md](claude/README.md).
